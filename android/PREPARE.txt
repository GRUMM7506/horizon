horizon-prepare для Android-порта Horizon
=========================================

Эта программа собрана из того же коммита, что и APK из того же прогона CI. Игра на телефоне
читает только ресурсы, подготовленные своей версией Horizon: ресурсы от другой версии (например,
от Horizon, установленного на ПК через лаунчер) она отвергнет при загрузке.

Что нужно на компьютере:

1. Minecraft: Java Edition 26.3, хотя бы раз запущенный из официального лаунчера.
2. server.jar версии 26.3. Ссылка на него лежит в файле
   %APPDATA%\.minecraft\versions\26.3\26.3.json, поле downloads.server.url.
3. JDK 25 (например, Eclipse Temurin 25). Нужен именно JDK: программа компилирует свои
   экспортёры. Java из лаунчера Minecraft не подойдёт.

Запуск в этой папке (PowerShell):

    .\horizon-prepare.exe --prepare --complete --server-jar "C:\путь\к\server.jar"

Нужны оба ключа: --prepare берёт файлы игры из вашей копии Minecraft, --complete добавляет звуки
и проверяет результат. Пути пишите целиком: PowerShell не раскрывает %APPDATA%.

Если Minecraft стоит не в C:\Users\ИМЯ\AppData\Roaming\.minecraft (другой лаунчер), добавьте
--minecraft-dir "ПАПКА", где ПАПКА содержит versions\26.3, libraries и assets.

Если Horizon уже установлен на этом компьютере через его лаунчер, файлы игры можно не искать:
скопируйте папку .local\minecraft из установленной версии
(C:\Users\ИМЯ\AppData\Roaming\horizon-launcher\versions\ВЕРСИЯ\.local\minecraft) в папку .local
рядом с этой программой: тогда --server-jar не нужен. Ключ --minecraft-dir для другого лаунчера
остаётся: из его папки берутся звуки.

Подготовка идёт несколько минут. Проверить результат: .\horizon-prepare.exe --check

Результат: папка .local\horizon-client\26.3 рядом с программой. Перенесите её на телефон в
Android/data/dev.horizonport.android/files/horizon/.local/horizon-client/26.3 (старую сначала
удалите), либо упакуйте .local в zip и импортируйте кнопкой в лаунчере. Остальное содержимое
.local на телефоне не нужно.

Ни один файл Minecraft в этом архиве не лежит: только программа Horizon, её Java-исходники
экспортёров и research-lock.json с контрольными суммами.

----

horizon-prepare for Horizon's Android port, built from the same commit as the APK of the same CI
run. The game only reads resources its own version prepared. You need Minecraft: Java Edition
26.3 played once from the official launcher, its server.jar, and a JDK 25. Run, in this folder:

    horizon-prepare --prepare --complete --server-jar /path/to/server.jar

and copy .local/horizon-client/26.3 to the phone (docs/android-port.md).
